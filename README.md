# Fitness Tracker 🏋️‍♂️

A C# Windows Forms application developed as part of the **NCC L4DC C# Assignment**.  
The project provides a fitness tracking system with role-based access for **Admin** and **Member** users.

---

## 📌 Features
- **User Authentication**
  - Login and Registration forms
- **Role-Based Dashboards**
  - Admin Home Page
  - Member Home Page
- **Activity Tracking**
  - Track workouts, progress, and fitness goals
- **User Management**
  - Admin can manage member accounts
- **Simple UI**
  - Built with Windows Forms for ease of use

---

## 🗂️ Project Structure
- `Program.cs` – Entry point of the application
- `LoginForm.cs` – User login interface
- `RegisterForm.cs` – User registration interface
- `MainForm.cs` – Core navigation form
- `AdminHomePage.cs` – Dashboard for admin users
- `MemberHomePage.cs` – Dashboard for member users
- Additional forms for extended functionality

---

## ⚙️ Requirements
- **IDE:** Visual Studio 2022 (or later)
- **Framework:** .NET Framework 4.7.2 (or compatible)
- **Language:** C#
